http4s

The ciris-http4s module provides ConfigDecoders for ip4s and http4s types.

Getting Started

To get started with sbt, add the following line to your build.sbt file.

libraryDependencies += "is.cir" %% "ciris-http4s" % "3.15.2"

If you are using Scala.js or Scala Native, make sure to replace %% with %%% above.

Usage

import ciris.env
import ciris.http4s._
import com.comcast.ip4s.Host
import com.comcast.ip4s.Port
import org.http4s.headers.Origin
import org.http4s.Uri

env("HOST").as[Host]
// res0: ConfigValue[Effect, Host] = ConfigValue$416360075
env("PORT").as[Port]
// res1: ConfigValue[Effect, Port] = ConfigValue$2025484307
env("ORIGIN").as[Origin]
// res2: ConfigValue[Effect, Origin] = ConfigValue$1436700244
env("URI").as[Uri]
// res3: ConfigValue[Effect, Uri] = ConfigValue$617669577
